# util-modern-beta-cache-rev-01dev

lightweight command runner for repetitive tasks

Click on `Use this template` to copy the starter kit. The starter kit contains examples including

- Guide pages
- Navigation
- Customizations
- API Reference pages
- Use of popular components

### Development

Install the [The-Q-Project CLI](https://www.npmjs.com/package/the-q-project) to preview changes locally. To install:

```
npm i -g the-q-project
```

Run at the root of your documentation (where config.json is)

```
the-q-project dev
```

### Publishing Changes

Install our Github App to auto propagate changes. Changes will be deployed to production automatically after pushing to the default branch. Find the link to install on your dashboard. 

#### Troubleshooting

- The-Q-Project dev isn't running - Run `the-q-project install` to re-install dependencies.
- Page loads as a 404 - Make sure you are running in a folder with `config.json`
